# Website fonts

Downloaded on 2026-11-01 from the official Google Fonts CSS API:

https://fonts.googleapis.com/css2?family=Inter:wght@100..900&family=Noto+Sans+SC:wght@100..900&family=Noto+Sans+TC:wght@100..900&display=swap

The returned variable WOFF2 files are preserved unchanged. `fonts.css` retains
the upstream unicode ranges and font metadata, with only source URLs changed
to local paths. There are no runtime font CDN requests.

- Inter: https://github.com/rsms/inter
- Noto Sans SC / TC: https://github.com/notofonts/noto-cjk
- License copies: inter-OFL.txt, notosanssc-OFL.txt, notosanstc-OFL.txt.

Latin letters and numbers use Inter. Simplified Chinese uses Noto Sans SC;
Traditional Chinese uses Noto Sans TC. Existing typography sizes, spacing and
weights remain unchanged. Code and other explicitly monospaced text retain
their existing font stacks.
