# 星象测试

主页在线服务入口对应 `/zh-cn/services/four-elements/`，另有繁体中文和英文导航路径。题目沿用原版简体中文，不涉及出生日期或星座计算，仅供娱乐与自我探索。

## 作答与计分

题库含 36 道评分题与 12 道两两选择题，每页 6 题。程序按原始规则计分，评分题权重 80%，两两选择权重 20%。匿名回归输入与期望结果位于 `tests/fixtures/four-elements/`。

进度自动保存在当前浏览器。末页提交后锁定本次作答，提交完整答案至本站接口，再由后端重建题目、选项和实际回答并发送至 DeepSeek。生成期间显示等待状态；失败可按原答案重试。清除数据经确认后清除本地草稿及报告并返回测试主页。

## 结果与 PDF

网页与 PDF 共用经过校验的 AI 内容：总览、固定方法说明、按实际倾向分组的解读、协同建议与收束。相距不超过六分的倾向编排在同一章节，每组均与组内最高项比较，避免连续合并扩大跨度。这是阅读编排规则，不是经过验证的心理分档。

v3 协议由程序确定章节成员和卡片布局，AI 根据全部题目与回答提供短段落、卡片正文、提炼句、字面强调词及依据。网页使用文本节点渲染；分数与图表始终由程序计算，依据默认折叠。

保存报告在浏览器中使用 pdf-lib 与 fontkit 生成可选择和检索的文字 PDF，不调用浏览器打印。A4 页面采用嵌入的常规及半粗中文字体、矢量元素图标、卡片与固定页眉页脚；不包含全部作答列表。字体授权见 `public/fonts/star-report/OFL.txt`，字体构建脚本见 `scripts/build-report-fonts.py`。

## 接口配置与验证

Node.js 24 后端、密钥占位、来源白名单、限流及部署步骤见 [AI 解读接口说明](../services/four_elements_api/README.md)。真实密钥只放在部署环境或被 Git 忽略的本地环境文件中。服务仅合并正在处理的相同请求，不落盘或缓存完成的作答与报告，不记录原始作答和上游完整响应。

```sh
node --test tests/four-elements*.test.mjs tests/report-emphasis.test.mjs
npm run build
```

接口测试使用模拟上游，不消耗真实模型额度。实际生成质量与费用需在配置密钥后联调。
