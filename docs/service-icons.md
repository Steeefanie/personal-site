# 在线服务入口图标

三枚入口采用统一尺寸及底板。拼豆使用彩色豆子网格，星象使用圆形徽章，二者由 `ServiceBadgeArt.astro` 绘制；七宗罪与七美德使用用户提供的原图，由 `SevenTraitsIcon.astro` 水平镜像呈现。

- 统一 72px 桌面底板、16px 圆角及随主题切换的背景；手机按同一比例缩放。
- 拼豆保留珠孔与排列特征，采用红、黄、蓝的多彩珠粒，不添加底部方盘；星象的四元素使用 `ServiceElementEmblem.astro` 中的实心曲线纹样，采用水蓝、火橙、土金、风青绿的独立配色，以星芒、外环构成徽章。首页入口、测试介绍页、网页报告与 PDF 共用 `element-icons.ts` 的四元素分层路径及配色，风统一为青绿色。
- 两枚矢量图标分别保留主题配色；拼豆以多彩珠粒网格表达手工工具，不使用圆环或星芒；星象外侧轨道分为四段弧线，避开四周星芒，星芒不加浅色描边。图片保持原始颜色、比例及透明度。
- 底板随主题使用纯白 `#fff`、深色 `#090909`，不添加边框；浅色使用轻黑色阴影，深色使用不透明度为 2.5% 和 1.5% 的两层白色微光。珠孔及四元素内部留空使用相同底色；入口标签继续使用网站主题文字颜色。徽章图案自身的圆环保留。
- 徽章外环及星芒用于服务入口；四元素纹样也用于介绍页、网页报告和 PDF。原 `ElementIcon.astro` 线框组件及旧路径已删除。

设计参考：[Material 产品图标的构图、网格及视觉比例](https://m1.material.io/style/icons.html)、[Fluent 产品入口图标及小尺寸可读性](https://fluent2.microsoft.design/iconography/)。具体尺寸和配色是本项目选择，并非这些规范强制要求。
