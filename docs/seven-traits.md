# 七宗罪与七美德测试

入口为各语言主页“在线服务”，保留 `/services/seven-traits/` 路径。题库和解读使用原版简体中文，繁体及英文页面显示语言说明。

## 题库与计分

来源为用户提供的《七宗罪七美德_56题完整复用包_V1.2》。保留原始 56 题及顺序，每轮 8 题，共 7 轮。每维 4 题，十四维独立计分；第 13 题归慷慨，第 50 题归耐心，仅第 39、50 题以 `6 - 原始答案` 反向计分。换算分为 `(调整后四题均值 - 1) × 25`，half-up 保留一位小数，与 V1.1 不混用。

## 与星象测试共用的实现

- `ServiceBackLink.astro`：返回主页并恢复在线服务位置。
- `questionnaire-draft.ts`：版本校验、草稿恢复、存储不可访问/损坏/写入或删除失败处理。
- `questionnaire-ai.ts`：提交完整性检查、请求超时、取消、重试、匹配当前答案的本地报告缓存。
- `questionnaire-download.ts`：Blob 下载与延迟释放。
- `questionnaire.css`：随页面滚动的翻页操作栏和等待转圈样式。
- `report-fonts.ts`、`report-pdf-text.ts`：同源中文字体、字体请求复用、失败后重试、换行及标点处理。
- 现有测评 API 服务：密钥、固定上游、来源检查、请求体限制、并发与调用额度。两套测试的缓存键、题库、输出校验和接口分别独立。

首页入口和测试介绍复用 `SevenTraitsIcon.astro`，纯白及深色 `#090909` 底色和深浅主题与其他服务入口一致。介绍页标题桌面 32px、手机 26px，答题缩为 20px；返回链接和默认展开的测试说明保持左对齐。

页面直接导入星象测试的 `four-elements.css`，并复用其介绍、答题、提交、报告和弹窗的展示类名；结果正文使用相同的 `.prose` 排版。`seven-traits.css` 仅补充十四维图表及数据配色等专属差异，避免另行维护一套字号、间距和基础颜色。

## 一次提交流程

进度自动保存在本地 `seven-traits-v1.2`。末页点击“提交”后，完整回答经本站服务发送至 DeepSeek，作答锁定；生成失败保留作答，支持重试，刷新后保持锁定。首次访问或刷新先显示测试主页；有报告时可直接查看。新流程不把本地基础结果伪装为已生成的 AI 报告。

AI 报告暂存于当前浏览器的 `seven-traits-ai-v3`，采用 `seven-traits-deepseek-v2` 协议；缓存版本与接口协议分别管理。旧版报告缓存失效且移除；作答、进度和提交锁定状态保留，恢复为已完成作答、等待手动生成的状态，升级本身不发起模型请求。清除同时删除作答和解读，解除锁定；迟到响应不会恢复已清除的数据。服务端只即时处理，不落盘保存答案或报告；浏览器保留记录，共用设备应结束后清除。已经发出的模型调用即使取消也可能计费。

## 报告与导出

网页与 PDF 共用 `seven-traits-report.ts` 内容模型：结果总览、计分方法、七组固定顺序章节、综合内容卡片与收尾观察。每章合并两侧维度卡片和关系解读，十四维各出现一次；分数由程序计算，不由模型提供。网页方法及逐题依据默认折叠，桌面和手机雷达图均显示维度名及分数，不显示梯度数字或另列得分表。清除数据与全部作答标题同排；仅保留 PDF 保存，不提供图表和原始数据导出入口。

PDF 使用现有 pdf-lib、fontkit 和本站中文字体，点击保存时才按需加载；为 A4、50pt 页边距，支持文字选择、复制和检索，不调用打印窗口。封面使用镜像原始 PNG，其他图形保持矢量；方法独立成页，每组从新页开始，长卡片可续页，不列解读依据题号，也不附五十六题作答清单；逐题依据仅在网页折叠查看。字体无法支持的罕见字符明确报错，不静默缺字。

两套测试共用 `report-dom.ts` 的正文、字面强调和卡片渲染，以及 `report-pdf-layout.ts` 的富文本测高、绘制、卡片测高和分页判断；保留星象自身的业务解读逻辑。`seven-traits-chart-layout.ts` 为网页与 PDF 提供同一轴位和计分图形。

七组各围绕一个核心发现展开：概述提出发现，维度卡片简述表现模式，关系分析解释区别或并存条件，补充说明仅在能提供新的关键区别时出现，不机械审查信息缺失。避免逐题改写选项、在相邻模块反复总结。综合卡片须联系至少两组对应维度，并校验其依据题号覆盖不同组；不能将相关性写成因果，也不能把可能解释当作固定动机。

强调候选与程序共用四至三十六字、每段零至一处、不超过段落一半的规则。保留必要的否定、条件和转折；同一模块重复出现的候选忽略。内容模型在原始段落上确定起止范围，网页和 PDF 使用同一结果，首行缩进和换行不重新选择重点。标题、提炼句已有结构强调，正文不再强调其相同片段；无效强调不导致整份报告失败。

模型输入显式列出十四维与七组的允许题号集合。双端检查完整覆盖、证据归属、正文非空、总体长度及文本安全；合理短段落、合并段落及重复依据可接受，无效强调直接忽略。两套测试共用环境与模型设置，默认 `deepseek-flash`，无自动付费重试。失败日志仅记录阶段、耗时与字段诊断。

后端提供 `/api/v1/seven-traits/report` 和 `/api/v1/seven-traits/health`，复用现有环境变量。部署需增加新路径的 Nginx 代理，并重启现有 API 服务，详见 `services/four_elements_api/README.md`。自动化测试和版式检查使用模拟上游；用户明确要求的真实联调单独执行，不自动重试。
